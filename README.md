# 🏛️ Premier Schools Exhibition (PSE) Landing Page

A production-ready, pixel-perfect **React 19 + TypeScript + Vite** web application built for the **Premier Schools Exhibition**, implemented strictly according to Figma design specifications.

🌐 **Live Demo**: [https://kanhopatrajagdambe-2024.github.io/srv-media-test/](https://kanhopatrajagdambe-2024.github.io/srv-media-test/)

---

## 🚀 Quick Start & How to Run

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+ or v20+ recommended)
- `npm` (Package Manager)

### 1. Clone the Repository
```bash
git clone https://github.com/kanhopatrajagdambe-2024/srv-media-test.git
cd srv-media-test
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

---

## 🛠️ Build & Deployment Scripts

### Build for Production
```bash
npm run build
```

### Preview Production Build Locally
```bash
npm run preview
```

### Deploy to GitHub Pages
```bash
npm run deploy
```

## ✨ Key Features & Technology Stack

- **Core Framework**: React 19, TypeScript, Vite
- **Styling & Aesthetics**: Custom CSS Tokens, Glassmorphism, Micro-animations, Responsive Media Queries
- **Components Implemented**:
  - **Standard Sticky Header**: Sleek 64px header with high-resolution 22nd Edition vector logo crest, nav tabs, and Register Now CTA button.
  - **Hero Section**: Responsive grid featuring venue details pill badge (`Apparel House, Sec 44, Gurugram`), 6 student activity pill photos, continuous auto-scrolling vertical image marquee, and an `Enquire Now` form card.
  - **Participating Schools**: 4 golden Laurel Wreath trust stat badges (`1 Million+ Parents`, `22+ Years Legacy`, `500+ Schools`, `17 Cities`), 2-row continuous horizontal logo ticker with heraldic crest emblems.
  - **School Categories**: Interactive card grid for International IB, Residential Boarding, CBSE & ICSE, and Pre-School categories.
  - **Exhibition Benefits**: Multi-card benefit showcase with interactive arrow controls.
  - **Latest Blogs Reader**: Searchable blog reader view with category filter chips, featured blog banner, and article modal popup.
  - **Registration Modal**: Glassmorphic modal popup dialog with backdrop blur, non-overlapping close icon, and confirmation screen.
- **Cross-Device Responsiveness**: 100% responsive across Desktop (1200px+), Tablet (768px - 1024px), Mobile (< 768px), and Small Mobile (< 480px).
